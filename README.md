# EasyDataAI

> Easy Data x AI 课程学习笔记与知识沉淀。

这个仓库用于记录课程中的核心概念、实践方法和学习复盘，逐步沉淀一套可检索、可复用的 AI 与数据知识体系。

## 学习主线

模型决定 AI “能想多好”，数据决定 AI “能做多好”。

遇到 AI 效果问题时，先判断缺少的是事实数据、实时数据、用户数据还是业务数据，再决定是否需要更换模型或补充检索、记忆与工具能力。
